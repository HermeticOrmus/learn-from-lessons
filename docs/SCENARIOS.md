# Scenarios (controlled vocabulary)

| id | the agent is … |
|---|---|
| `any` | any situation (most principles) |
| `writing-paper` | drafting or revising a paper, rebuttal, abstract, captions |
| `writing-outward` | emails, docs, blogs, applications, decks for other readers |
| `figures-visual` | figures, tables, diagrams, slides, UI visuals |
| `coding` | writing or changing code |
| `debugging` | finding and fixing a failure |
| `experiments` | designing, launching or analysing runs, evaluations, data |
| `research-ideation` | discussing ideas, framing, methods, research questions |
| `planning-discussion` | the person is discussing, asking why/how, or asking for a plan |
| `release-deploy` | git push, PRs, releases, deployments, shared remotes |
| `reporting` | reporting status or results back to the person |
| `long-autonomous` | working unattended for a long stretch |
| `cost-resources` | spending API credit, compute, paid services |
| `product-design` | deciding what a product or feature should do, its flows and scope |

Extend only when a new scenario has ≥ 3 lessons; keep ids short and kebab-case.
